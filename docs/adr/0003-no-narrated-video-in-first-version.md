# 首版不製作完整旁白影片

首版媒介限於文字、圖解與互動 HTML。被要求影片時說明能力範圍，提出腳本／分鏡等可行選項，並以其實際形式交付，不稱為已製成影片。影片在原始解說概念中是候選媒介，但製作成本、工具依賴與驗證方式都遠高於其他形式，故刻意排除；這是範圍上的「不做」，不是遺漏。決策過程見 `.scratch/karpathy-concept-skill/issues/04-media-scope.md`。

**Falsified if:** `skills/answer-me/SKILL.md` 的「文件、圖解與 HTML」一節不再把完整旁白影片列為首版範圍外，或專案新增產生影片的流程。

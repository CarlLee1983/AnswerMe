# 核心獨立運作，製作能力只作可選依賴

`answer-me` 自行負責理解目標、選型、解說組織、證據呈現與成果檢查；`show-me`、`archify`、`visualize` 等只在當前環境可用且適合時選用，不是固定路由。曾比較「自成一體」與「固定路由到指定技能」：前者會重複既有媒介指引，後者讓簡單解說也背上依賴，且某個整合失效就拖垮整個技能。選定方向讓單一整合可停用而不影響其餘承諾的行為。決策過程見 `.scratch/karpathy-concept-skill/issues/06-skill-boundary.md`。

**Falsified if:** `skills/answer-me/SKILL.md` 要求某個外部技能必經才能完成任一交付格式，或技能目錄開始內建本該由製作能力負責的媒介指引，而非只保留 `skills/answer-me/references/html-style.md` 這類預設樣式。

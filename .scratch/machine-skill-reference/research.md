# machine-skill 上游證據筆記

查閱版本：AirsupHQ/machine-skill [`537bb665ab03f29ad4f4124b8af76cbfda47a6c9`](https://github.com/AirsupHQ/machine-skill/tree/537bb665ab03f29ad4f4124b8af76cbfda47a6c9)。以下是原始碼與技能文字的靜態檢查；未執行上游程式，也未驗證展示成品的物理正確性。

1. **可借「主輸入 → 計算模型 → 主讀值／運動／故障」的產出約束。** 技能要求一個主要滑桿、一個主要數值，且數字與動畫都由小型求解器帶動；`breakIt` 要改變模型狀態，讓結果由模型算出。模板確實留下 parts、solver、break/explain 四個填寫區，範例的葉片脫落也計算動能與失衡力。這是建模與教學的結構參考；模板本身的 `P = input` 和空的 `breakIt` 僅是佔位，不能當作物理品質的保證。[技能流程](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/SKILL.md)、[模板](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/kit/template.html)、[渦扇範例](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/examples/turbofan.html)

2. **可借「公開基準點 + 模型簡化揭露」作內容驗收。** 技能要求先記真實尺寸、方程、常數、工作點，再將算出的工作點與公開數值比對；偏差超過約 20% 要修模型，交付時說明簡化。這是作者指令，原始碼中沒有看到會自動查證來源或物理精度的驗證器。[技能研究與 solver 小節](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/SKILL.md)

3. **可借「固定狀態的多視角視覺審查」，但目前是人工門檻。** `shot.mjs` 能對初始、操作後與 film 指定時刻截圖，並印出 fps、零件數、三角形數、材質數與 draw calls；`--steps` 能在同一載入中連續拍多個狀態。技能要求至少四輪，每輪看全景、剖面、拆解、接點特寫與影片影格。腳本只把頁面／主控台錯誤印出，並不直接因那些訊息、低 fps、幾何穿插或難看的畫面而失敗；讀圖與修正仍靠執行者。[截圖腳本](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/scripts/shot.mjs)、[瀏覽器啟動器](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/scripts/lib/browser.mjs)、[技能審圖規則](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/SKILL.md)

4. **可借「先截取，再掃描輸出」的機器可判定瑕疵門檻。** 共用 `guardPage` 對 PNG 擷取先測洋紅色像素；純洋紅持續時重試八次並拋錯，超過 25% 粉色則重試。`record.mjs` 逐格取得 PNG、檢查 WebGL context loss，產片後用 `pinkscan` 掃描並以非零碼報錯。限制：一般粉色畫面重試用盡後會保留；JPEG 分支會在驗證 PNG 之後重新截一張 JPEG；掃描失敗時影片已寫出，這是偵測失敗而非阻止輸出。對 AnswerMe 可借「針對已知渲染故障的具體影像偵測」原則，無須照搬洋紅色門檻。[guard](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/scripts/lib/guard.mjs)、[像素統計](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/scripts/lib/png.mjs)、[錄影](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/scripts/record.mjs)、[掃描](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/scripts/pinkscan.mjs)

5. **`evals.json` 是情境清單，並非已證實通過的自動評測。** 五題涵蓋渦扇、機械錶、LVAD 醫療說明、水輪機連影片、V8；每題有自然語言 `expected_output`，包括幾何、模型、互動與影片要求。檔案沒有判斷式、量測紀錄或輸出結果；上游樹亦沒有看到連接此檔的測試程式或 CI workflow。因此可借「多領域且包含失效狀態的情境樣本」，但須自行定義可觀察的斷言與實際執行紀錄，不能把五個預期敘述當作能力證明。[評測檔](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/evals/evals.json)、[套件指令](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/package.json)、[該版檔案樹](https://github.com/AirsupHQ/machine-skill/tree/537bb665ab03f29ad4f4124b8af76cbfda47a6c9)

6. **模板與 runtime 適合借介面契約，不適合整套搬入。** `template.html` 把場景、零件、模型、說明／互動分成四段；`lab-kit.js` 統一相機、材質、剖面、拆解、讀值與影片時鐘；`inline.mjs` 把 kit 嵌入單一 HTML。這降低每次製作的重複設定，但 runtime 依賴瀏覽器中的 Three.js CDN，且聚焦 3D 機械與影片。若 AnswerMe 要吸收，較通用的是清楚的模板填寫位置、狀態接口與可重現檢查，不是其 3D 資產與錄影工作流。[模板](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/kit/template.html)、[runtime](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/kit/lab-kit.js)、[內嵌腳本](https://github.com/AirsupHQ/machine-skill/blob/537bb665ab03f29ad4f4124b8af76cbfda47a6c9/scripts/inline.mjs)

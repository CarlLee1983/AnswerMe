# 現有解說技能能提供哪些能力，缺少哪些環節？

Type: research
Mode: AFK
Status: resolved
Part of: [把 Karpathy 的解說概念轉成可重用 skill](../map.md)

## Question

已安裝的 `show-me`、`visualize`、`archify` 與 `imagegen` 能支援哪些解說形式？它們的能力宣告與實際驗證有何差別？哪些能力尚不足以承諾完整的客製解說影片？

## Resolution criteria

保存帶原始檔位置的能力盤點，區分文字宣告與執行驗證。盤點只供邊界決策使用，不直接決定新 skill 必須依賴哪些工具。

## Answer

已匯入 `skill_consumers` 的 read-only scout 結論，保存為[既有解說能力盤點](../research/existing-capabilities.md)。筆記包含四份原始 skill 指引的位置，以及盤點和驗證的範圍。

現有指引涵蓋文字搭配圖解、互動 HTML、點陣圖與動畫圖的 WebM 匯出。盤點沒有找到完整客製旁白解說影片的產製流程，亦未實際執行各媒介工具。影片可行性和選定依賴的執行驗證，僅在後續確定需要時另立研究或 prototype 票。

這份證據供後續比較技能邊界，不指定採用自成一體、選擇性整合或固定路由。

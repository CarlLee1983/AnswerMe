# 03: 網站瀏覽器檢查

**What to build:** 維護者手動執行一支瀏覽器檢查，以 `file://` 與離線模式開啟網站目錄的每一頁，確認沒有執行期例外、範例頁零 HTTP(S) 請求、390 px 寬度沒有水平溢出；有互動控制項的頁面會操作主要控制項並確認結果改變。截圖與 JSON 結果寫入新的暫存目錄並印出路徑。做法參考既有的模板瀏覽器檢查與 CDP 輔助程式。先以介紹頁跑通。規格見 [spec.md](../spec.md)。

**Blocked by:** 02（最小介紹頁上線）

**Status:** ready-for-agent

- [x] 對介紹頁執行通過，產出桌面與 390 px 截圖及 JSON 結果，且不寫入 repo。
- [x] 刻意加入外部請求或執行期錯誤的暫時頁面會使檢查失敗並以非零狀態結束（驗證後移除暫時頁面）。
- [x] 介紹頁的 Google Fonts 請求不被視為失敗；範例頁的任何 HTTP(S) 請求皆視為失敗。
- [x] 檢查說明文件補上執行方式、需求（Node.js 與 Chrome／Chromium）與範圍。

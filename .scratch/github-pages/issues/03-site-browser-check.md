# 03: 網站瀏覽器檢查

**What to build:** 維護者手動執行一支瀏覽器檢查，以 `file://` 與離線模式開啟網站目錄的每一頁，確認沒有執行期例外、範例頁零 HTTP(S) 請求、390 px 寬度沒有水平溢出；有互動控制項的頁面會操作主要控制項並確認結果改變。截圖與 JSON 結果寫入新的暫存目錄並印出路徑。做法參考既有的模板瀏覽器檢查與 CDP 輔助程式。先以介紹頁跑通。規格見 [spec.md](../spec.md)。

**Blocked by:** 02（最小介紹頁上線）

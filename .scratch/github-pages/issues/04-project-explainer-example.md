# 04: 範例：專案自我介紹

**What to build:** 訪客從介紹頁的範例卡片點進一頁由 answer-me v0.1.3 產生的範例：以 v0.1.3 tag 下的 repo 本身為素材，產生一份文章式專案介紹，說明 Answer Me 是什麼、如何運作。範例由只拿到 v0.1.3 技能、一段使用者請求與原始素材的獨立 agent 產生；維護者核對後在頁面外框加上「由 answer-me v0.1.3 產生」、產生日期與「經人工核對」，並把指向 repo 檔案的來源連結改為固定於 v0.1.3 tag 的 GitHub 網址，不改動解說內文。介紹頁補上這張範例卡片，說明它示範的情境與形式。暫存目錄中的歷史評測成品不移動、不改寫。規格見 [spec.md](../spec.md)。

**Blocked by:** 01（網站檢查防線）、02（最小介紹頁上線）、03（網站瀏覽器檢查）

**Status:** ready-for-agent

- [ ] 產生用的 agent 沒有拿到本規格、歷史評測成品或驗收條件；請求原文記錄在核對紀錄中。
- [ ] 頁面標示讓讀者看出它描述的是 v0.1.3 時的 repo 狀態，而非網站加入後的狀態。
- [ ] 頁面為單檔 HTML，不載入任何外部資源；網站檢查防線與瀏覽器檢查皆通過。
- [ ] 來源連結全部指向 v0.1.3 tag，且行號與內容對得上；改寫的連結列在核對紀錄中。
- [ ] 版本、日期與人工核對標示已加入頁面外框。
- [ ] 介紹頁的範例卡片已加入並連到本頁。
- [ ] 核對紀錄寫入本功能目錄的驗證紀錄，區分已實測與只經靜態檢查的部分。
- [ ] 維護者過目同意後才合併。

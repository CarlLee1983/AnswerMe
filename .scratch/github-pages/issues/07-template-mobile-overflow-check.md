# 07: 模板手機版溢出檢查實際生效

**What to build:** 維護者執行模板瀏覽器檢查時，390 px 手機版若有水平溢出，檢查會失敗。目前的斷言以 `scrollWidth <= innerWidth` 判斷，但在行動裝置模擬下 Chrome 會把 `innerWidth` 撐到內容寬度，這條斷言永遠成立。第 03 張網站瀏覽器檢查已改為與固定的 390 px 比較；模板檢查應採相同判準。此問題在實作第 03 張時發現，見 [03-site-browser-check.md](03-site-browser-check.md)。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 先以一份寬於 390 px 的暫時模板副本證明現有斷言不會失敗（RED），驗證後不留在 repo。
- [ ] 手機版斷言改與固定的 390 px 比較；同一份過寬副本使檢查失敗並以非零狀態結束。
- [ ] 兩份內建模板（文章式與簡報式各頁）在修正後的檢查下仍通過；若實際溢出，回報而不是放寬斷言。
- [ ] 不修改模板本身，除非上一項確認有真實溢出且維護者同意修正。
- [ ] 檢查說明文件若描述了溢出判準，同步更新。

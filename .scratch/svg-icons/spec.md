# 介紹頁 SVG 圖示：幫助掃讀與提示操作

Status: ready-for-agent

## Problem Statement

訪客瀏覽介紹頁時，並列的類別只靠文字區分：兩種用途（概念學習、成果審視）與能力邊界的四項（language、media、html、scope）在快速捲動時不易一眼分辨。可操作的元素也缺少提示：複製按鈕只有文字，點擊後的狀態只靠文字變化；連結一律以文字「→」結尾，看不出哪些會離開網站前往 GitHub，哪些是站內跳轉。

## Solution

在介紹頁加入一組風格一致的線條 SVG 圖示，只放在能帶資訊的位置：用途卡與能力邊界各項前加上代表該類別的圖示；複製按鈕帶複製圖示，成功後換成勾選圖示再恢復；外部連結的箭頭改為外連箭頭，站內連結改為向右箭頭。所有圖示都是裝飾性的，文字照舊完整可讀；hero 模擬終端機裡的符號維持文字。圖示取自開源圖示集 Lucide，內嵌於頁面，網站仍可離線開啟、不載入外部資源。範例頁不變。

## User Stories

1. As a 網站訪客, I want 兩種用途卡各有代表圖示, so that 我捲動時一眼分得出概念學習與成果審視
2. As a 網站訪客, I want 能力邊界的四項各有代表圖示, so that 我能快速找到關心的那一項限制
3. As a 網站訪客, I want 圖示意義和旁邊的文字一致, so that 圖示不會誤導我對該項的理解
4. As a 網站訪客, I want 複製按鈕上有複製圖示, so that 我不讀文字也知道它的用途
5. As a 網站訪客, I want 複製成功後按鈕顯示勾選圖示, so that 我確定指令已經複製
6. As a 網站訪客, I want 按鈕在幾秒後恢復原狀, so that 我可以再次複製
7. As a 網站訪客, I want 剪貼簿被拒時按鈕仍給出清楚回饋, so that 我知道要自行按快捷鍵複製
8. As a 網站訪客, I want 外部連結帶外連箭頭, so that 我點之前就知道會離開網站
9. As a 網站訪客, I want 站內連結帶向右箭頭, so that 我分得出這是頁內或站內跳轉
10. As a 網站訪客, I want 頁首、頁尾與 hero 的 GitHub、Releases、README 與 Skills CLI 連結都用同一種外連箭頭, so that 外部連結的提示前後一致
11. As a 網站訪客, I want hero 模擬終端機維持文字符號, so that 它看起來仍像真實的終端機輸出
12. As a 網站訪客, I want 圖示顏色跟著所在文字, so that 連結懸停與強調色變化時圖示一起變
13. As a 網站訪客, I want 圖示大小與文字相稱並對齊基線, so that 版面不顯得凌亂
14. As a 手機上的訪客, I want 加入圖示後頁面仍無水平捲動, so that 閱讀不受影響
15. As a 使用螢幕閱讀器的訪客, I want 圖示不被朗讀, so that 我聽到的內容與改版前相同、沒有多餘雜訊
16. As a 使用螢幕閱讀器的訪客, I want 複製結果仍由既有的狀態區宣告, so that 我知道複製是否成功
17. As a 離線開啟網站的訪客, I want 圖示在沒有網路時照常顯示, so that 頁面完整
18. As a 維護者, I want 每個圖示只定義一次並在各處引用, so that 換圖示只需改一處
19. As a 維護者, I want 圖示來源、版本與授權寫在圖示定義旁, so that 我知道從哪更新、授權義務也已履行
20. As a 維護者, I want 網站檢查與瀏覽器檢查在改版後照常通過, so that 圖示不引入外部資源或版面問題
21. As a 維護者, I want 複製按鈕的實際點擊行為有截圖紀錄, so that 自動檢查不涵蓋的互動也有證據
22. As a 維護者, I want 範例頁維持原樣, so that 它們仍如實呈現 v0.1.3 的產出

## Implementation Decisions

- **只改介紹頁**；範例頁（含其頂端外框）不變。
- **圖示來源**：Lucide（ISC 授權），固定於 lucide-icons/lucide commit `500620a2e8123f8d1db191538886dc0c223f69a9`，只取用到的圖示 path。以下 15 個名稱已在該 commit 確認存在，實際使用其中 10 個。
- **嵌入方式**：頁面內一份隱藏的 SVG sprite，每個圖示定義為一個 symbol，使用處以頁內片段引用。sprite 內以 HTML 註解寫明 Lucide、ISC 全文所需的 copyright 聲明、來源 repo 與 commit SHA。頁內片段引用沒有路徑，網站靜態檢查會略過，不需改檢查器（已查證）。
- **圖示對照**：

  | 位置 | 圖示 |
  | --- | --- |
  | 用途卡「概念學習」 | `book-open` |
  | 用途卡「成果審視」 | `git-compare` |
  | 能力邊界 language | `languages` |
  | 能力邊界 media | `video-off` |
  | 能力邊界 html | `file-code` |
  | 能力邊界 scope | `target` |
  | 複製按鈕，點擊前 → 成功後 | `copy` → `check` |
  | 外部連結 | `arrow-up-right` |
  | 站內連結 | `arrow-right` |

  外部連結：頁首導覽與頁尾的 GitHub、Releases，hero 的 repo 連結，頁尾的 README 安裝說明與 Skills CLI。站內連結：四張範例卡的「打開範例」與 CTA 的「先看範例」。原本文字裡的「→」由圖示取代。GitHub 不用品牌圖示。
- **不改的符號**：hero 模擬終端機的完成標記「✓」與「交付 →」維持文字。
- **樣式**：圖示用 `currentColor`、大小約 1em、線寬 1.75、對齊文字基線；與文字間距一致。
- **無障礙**：所有圖示 `aria-hidden="true"` 且不可聚焦；每個控制項保留可見文字，沒有只有圖示的按鈕。既有的螢幕閱讀器狀態區宣告不變。
- **複製按鈕**：按鈕內分為圖示與文字兩部分。現行腳本以整個按鈕的文字內容切換狀態，會把圖示一併清掉，改為只更新文字部分，並在成功時切換為勾選圖示、恢復時換回複製圖示。剪貼簿被拒的退路（選取文字、提示快捷鍵）保留；此情況不顯示勾選圖示。恢復時間 3 秒。

## Testing Decisions

- 這是純呈現改動，沒有可先寫失敗測試的邏輯，不走 RED→GREEN；驗收沿用既有接縫，只觀察外部行為。
- **網站靜態檢查**（檢查器的網站掃描）：改版後通過，代表沒有引入外部資源、本機路徑或壞掉的站內連結。檢查器行為未變，不新增檢查器測試。
- **網站瀏覽器檢查**：改版後全頁通過（無執行期例外、桌面與手機無水平溢出），並人工目視桌面與手機截圖，確認圖示位置、大小、對齊與顏色。
- **複製按鈕實操**：以 Playwright 開啟介紹頁點擊複製按鈕，確認圖示換成勾選、文字切換、按鈕內 SVG 仍在、3 秒後恢復；截圖與結果記入本功能目錄的驗證紀錄。不為此擴充瀏覽器檢查程式。
- 先例：GitHub Pages 功能的驗證紀錄（截圖加區分已實測與只經靜態檢查的部分）。

## Out of Scope

- 範例頁與其外框。
- 範例卡的分類 tag、各段 `h2` 加圖示，或任何純裝飾圖示。
- GitHub 等品牌圖示。
- 替換現有的 webp 插圖、logo 或 favicon。
- 為複製按鈕新增自動化瀏覽器斷言。
- README 中的第三方授權說明（授權聲明只放在 sprite 內）。

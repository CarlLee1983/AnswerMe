# 03: 複製按鈕的圖示與狀態

**What to build:** 兩個複製安裝指令的按鈕帶複製圖示；複製成功後換成勾選圖示並顯示「已複製」，3 秒後恢復；剪貼簿被拒時維持既有退路（選取文字、提示快捷鍵），不顯示勾選。螢幕閱讀器的狀態宣告不變。

**Blocked by:** 01（圖示 sprite 與連結箭頭）

**Status:** ready-for-agent

- [ ] 按鈕內分為圖示與文字兩部分；狀態切換只更新文字部分，按鈕內的 SVG 不被清掉
- [ ] 成功時 `copy` → `check`，3 秒後換回 `copy` 與原文字
- [ ] 剪貼簿被拒時文字與狀態區宣告照舊，圖示維持 `copy`
- [ ] 按鈕仍有可見文字與既有的 `aria-label`

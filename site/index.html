ANSWER ME · AGENT 解說技能

看懂陌生的東西，也看懂 agent 做了什麼

Answer Me 是一個 agent 技能：它把陌生概念、repo 的運作，以及 agent 交出的方案、diff 與測試結果，整理成有依據的文字、圖解或可離線開啟的 HTML，並在關鍵主張旁附上來源。

兩種用途

技能先判斷你卡在哪裡，再決定用文字、圖解或互動呈現。未指定輸出方式時，它會先問一次要 HTML、Markdown 文件，還是直接在對話中回答。

概念學習

理解陌生概念、文章或系統

閱讀原文、程式與文件，沿一條實際流程追到負責的程式，幫你建立可運用的認識，而不是只給目錄清單。

成果審視

理解 agent 的方案、變更與執行結果

對照 diff、受影響的流程與測試紀錄，說清前後行為與取捨，並核對關鍵主張的證據。agent 自稱成功不算驗證證據。

安裝

使用 Skills CLI 安裝到使用者層級：

npx skills@latest add CarlLee1983/AnswerMe --skill answer-me -g

指定 agent、專案層級安裝、確認安裝與更新方式，見 README 的安裝說明。

能力邊界

  • 繁體中文為主：預設以繁體中文解說並保留必要英文術語；你明確要求其他語言時才改用該語言。
  • 不製作旁白影片：媒介限於文字、圖解與互動 HTML。要求影片時，會提供腳本或分鏡，並以實際形式交付。
  • HTML 為單檔離線：產出的 HTML 內嵌所需的樣式、程式與資料，不需要伺服器或安裝套件；預設模板的網路字型只增強外觀，離線時改用本機字型。
  • 解說不是 code review：技能協助理解並核對關鍵證據；完整審查或修改程式屬於另外的任務。

能力邊界

寫在前面，不寫在小字裡。

language
繁體中文為主，保留必要英文術語；明確要求時可用其他語言。
media
不製作旁白影片；媒介限於文字、圖解與互動 HTML。
html
單檔、離線可開，內嵌所需的樣式、程式與資料，不需要伺服器。
scope
解說不是 code review；完整審查或修改程式屬於另外的任務。

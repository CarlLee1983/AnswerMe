# HTML 預設樣式與版型

供不同 agent 製作 HTML 解說時共用。這是可調整的起點；來源、證據與交付驗證仍依 [SKILL.md](../SKILL.md)。

## 選擇與調整

優先順序：需求發起者的明確要求 → 內容與使用情境 → 預設樣式。

| 情境 | 起點 | 組織方式 |
| --- | --- | --- |
| 未指定版型、自行閱讀、深入理解或需要反覆查閱 | [文章式](../assets/article.html) | 先給核心說明，按問題展開流程與證據，允許自然捲動。 |
| 明確要求簡報式、逐頁講述或會議分享 | [簡報式](../assets/slides.html) | 每頁一個重點，依「問題 → 關係或機制 → 證據 → 判斷」組織；頁數依內容調整。 |
| 指定品牌色、深色、字型、版型或參考設計 | 最接近的模板 | 依要求調整。保留可讀性、來源與離線能力；需求與離線要求衝突時說明取捨。 |

HTML 是交付載體；文章式、簡報式是呈現方式。簡報式 HTML 不等同於 PPTX 或 Google Slides；使用者明確指定其他格式時，沿用該格式與相應能力。

未指定樣式時直接選用預設，交付時可簡述選擇，無須增加一輪詢問。內容不需要的區塊直接刪除；有長篇程式碼或密集表格時，文章可完整展開，簡報則拆頁並保留必要來源，不縮小字體硬塞。

## 共用視覺基礎

預設採淺色、暖中性背景與深綠重點色。顏色只用於分組與強調，狀態同時以文字表達。兩個模板以相同 CSS custom properties 承載基礎色彩，方便一次調整配色；每個成品仍是獨立檔案。

| Token | 預設值 | 用途 |
| --- | --- | --- |
| `--bg` | `#f7f6f2` | 閱讀背景 |
| `--surface` | `#ffffff` | 內容表面 |
| `--ink` | `#21352b` | 主文字 |
| `--muted` | `#526258` | 次要文字與來源 |
| `--accent` | `#25634a` | 連結、重點與導覽 |
| `--line` | `#d7ded5` | 分隔線 |
| `--soft` | `#e8efe5` | 摘要與輕量強調 |
| `--code-bg` | `#eef1ea` | 程式碼區域 |

- **字體與層級**：使用本機系統字體及繁體中文 fallback，程式碼使用 monospace。文章正文以約 18 px、1.8 行高為起點，正文行寬約 72 ch；簡報以較大的標題與較短的段落呈現。
- **間距與版面**：間距以 8 px 的倍數為主，整體寬度上限約 1120 px。用留白與細分隔線區分章節；避免裝飾性動態、強烈陰影與漸層占用閱讀注意力。
- **手機閱讀**：390 px 寬度下轉為單欄，不讓整份文件水平溢出。長程式碼與表格可在自己的容器中水平捲動；圖解與簡報內容要能完整閱讀。
- **操作與列印**：連結與按鈕有可見焦點；簡報提供前後頁、頁碼、方向鍵及 Home／End，鍵盤操作不干擾可編輯欄位或其他控制項。無 JavaScript 時仍能閱讀全文；列印包含所有頁面，略去導覽控制項，沿用所選配色。深色版本需檢視列印預覽，必要時啟用背景圖形；使用者要求省墨時再另調整列印樣式。

## 共用內容元件

| 元件 | 內容要求 |
| --- | --- |
| 摘要 | 先說核心結論與適用範圍。 |
| 流程或關係圖 | 節點與箭頭對應來源，提供文字標籤或可讀的替代說明。 |
| 比較表 | 比較相同面向，將差異與限制寫清楚。 |
| 程式碼 | 保留理解所需的上下文，標明來源；示例需明確標示。 |
| 來源與限制 | 放在相關主張附近，區分事實、推論、示意與未驗證部分。 |

元件是可選的內容形狀，不是每份解說必須填滿的表單。簡報導覽協助逐頁閱讀；模型輸入、滑桿等互動仍須能幫助理解才加入。

## 從模板到成品

1. 將選定的模板複製到本次交付位置，保留技能包中的原始模板。
2. 依需求修改標題、章節、圖解、示例與來源；新增或刪除頁面後核對導覽。模板附的示例內容不是本次任務的證據，只有全部替換後才移除示例標示。
3. 修改配色時優先調整 CSS tokens，核對文字對比與焦點可見性；指定字型若不在本機，選擇本機 fallback 或內嵌可合法使用的資源。成品不依賴模板旁的其他檔案。
4. 沿用技能的離線與開啟流程，實際檢查桌面、390 px 排版與來源連結。簡報另測首尾頁、按鈕與鍵盤操作、無 JavaScript 全文閱讀及列印所有頁面；示例模板通過檢查不代表新成品已驗證。
